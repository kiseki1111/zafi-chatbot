
3 perubahan utama  di Prisma 7.8 dan solusi yang diterapkan pada proyek ini:

1. PERUBAHAN ARSITEKTUR
- Koneksi Database: PrismaClient tidak bisa lagi menggunakan string URL secara langsung. Sekarang diwajibkan memakai Driver Adapter bawaan database (menggunakan library `pg` dan `@prisma/adapter-pg`).
- File Config Terpusat: Konfigurasi `seed` sudah dihilangkan dari `package.json`. Seluruh konfigurasi CLI kini wajib diletakkan di dalam file `prisma.config.ts`.
- Isu Pembacaan .env: CLI Prisma 7 terkadang gagal memuat file `.env` secara otomatis. Solusinya adalah menggunakan bantuan `dotenv-cli` untuk menyuntikkan variabel lingkungan sebelum perintah Prisma dijalankan.

2. SHORTCUT TERMINAL (DI PACKAGE.JSON)
Untuk mengatasi isu pembacaan `.env` tanpa menuliskan password database secara langsung (hardcoded), sistem eksekusi kini dibungkus dalam shortcut NPM:

* npm run prisma:migrate
  (Perintah asli: npx dotenv-cli -e .env -- npx prisma migrate dev)
  Fungsi: Membuat tabel fisik di database berdasarkan schema.prisma.

* npm run prisma:seed
  (Perintah asli: npx dotenv-cli -e .env -- npx prisma db seed)
  Fungsi: Menjalankan file seed.ts untuk mengisi data master (Role & Permission).

* npm run prisma:studio
  (Perintah asli: npx dotenv-cli -e .env -- npx prisma studio)
  Fungsi: Membuka antarmuka web untuk melihat isi tabel database.
