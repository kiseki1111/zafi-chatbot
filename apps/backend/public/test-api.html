RBAC Tester

Gunakan tombol-tombol di bawah ini untuk menguji apakah akun yang sedang login memiliki izin (permission) untuk mengakses API tersebut. Cek console di sebelah kanan untuk melihat status kode responsnya.
Users API
Get All Users GET /api/v1/users (Requires user:read)
Create User POST /api/v1/users (Requires user:create)
Update User PATCH /api/v1/users/:id (Requires user:update)
Delete User DELETE /api/v1/users/:id (Requires user:delete)
Roles API
Get All Roles GET /api/v1/roles (Requires role:read)
Create Role POST /api/v1/roles (Requires role:create)
Update Role PATCH /api/v1/roles/:id (Requires role:update)
Delete Role DELETE /api/v1/roles/:id (Requires role:delete)
Permissions API
Get All Permissions GET /api/v1/permissions (Requires permission:read)
Create Permission POST /api/v1/permissions (Requires permission:create)
Update Permission PATCH /api/v1/permissions/:id (Requires permission:update)
Delete Permission DELETE /api/v1/permissions/:id (Requires permission:delete)
Assignments API
Assign Role to User POST /api/v1/user-roles (Requires assignment:create)
Assign Permission to Role POST /api/v1/role-permissions (Requires assignment:create)
